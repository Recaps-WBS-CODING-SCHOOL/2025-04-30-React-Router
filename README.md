# React Router Demo Project

This project demonstrates the implementation of React Router v7 in a React application.
It showcases various routing features and best practices for building modern React applications with efficient navigation.

## Features

### React Router v7 Implementation

- **BrowserRouter** setup as the foundation for client-side routing
- **Route declarations** in App.jsx with a mix of static and dynamic routes
- **Nested routes** demonstrating parent-child relationship between components
- **Dynamic routes** with URL parameters (e.g., `/users/:id`)

### Navigation Components

- **Navbar component** for site-wide navigation
- **Layout component** providing consistent structure across pages

### React Router Hooks

- **useOutletContext** for passing data from parent routes to child routes
- **Custom fetch hooks** demonstrating how to work modular and split up logic

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Built With

- [React](https://reactjs.org/) - UI library
- [React Router v7](https://reactrouter.com/) - Routing library
